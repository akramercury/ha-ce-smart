# Brand assets for home-assistant/brands

To get the CE Smart icon showing in Home Assistant's UI, submit these to
https://github.com/home-assistant/brands as a `custom_integrations` domain.

Layout expected by that repo:

    custom_integrations/ce_smart/icon.png   (512x512, this icon.png)
    custom_integrations/ce_smart/logo.png   (this logo.png)

Requirements: trimmed transparent PNG, icon square (256 or 512), hAss-reviewed.
